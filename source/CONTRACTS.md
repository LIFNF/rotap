# 固定协议合约

元件价格、共享终身发行上限与流片费没有修改接口。正式部署须封存工厂、挖矿、市场，并将工厂信标、挖矿、市场及账户信标的 owner 永久置零。

ROTAP 只能由排放账本按固定公式发行。元件消耗不恢复额度。质押本金与协议收入分属不同合约，退出等待七天，追加申请重置等待期。

正式数据只使用 config/task-bank.json 与 config/vectors/ 的 4663 目标信息；reference-v2/ 是历史证据。

没有已核验的主网地址时不得填入本地地址。发布前必须通过所有测试、独立审查、链上运行时代码及权限核验和浏览器源码验证。详见 README.md、SECURITY.md 与 THIRD_PARTY_NOTICES.md。
