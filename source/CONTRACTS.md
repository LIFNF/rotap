# 固定协议合约

元件价格、共享终身发行上限与流片费没有修改接口。正式部署须封存工厂、挖矿、市场，并将工厂信标、挖矿、市场及账户信标的 owner 永久置零。

元件单价为 0.0002445 ETH，每笔协议费为 0.0003227 ETH，所有钱包统一付费。元件合约收取精确报价后，在同一笔 Mint 交易自动将价款和协议费转至固定收款人；正式发行的两个收款人均为部署者 0x8638636536Ed50fC1cCCDFDa1790aCC83E39643A。转款失败则 Mint 回滚。元件合约没有收入余额记账或提款接口。元件消耗不恢复累计发行额度。

ROTAP 精度为 8 位，固定总量 20,000,000 枚。挖矿账本部署代币时持有全部库存，部署者和其他钱包初始分配为零。代币没有后续增发入口；账本没有管理员库存提取或授权入口。挖矿领取通过账本转账释放已结算奖励，代币 `totalSupply` 不随领取增加；`totalClaimed` 与挖矿 `totalMined` 记录实际领取量。

初始全网挖矿预算为每天 7,200 枚，每 126,000,000 秒减半。按减半周期内累计预算的整数差结算，全局累计预算不超过固定总量；已验证与未验证池分别按 99% / 1% 分配并按有效权重结算，最小单位取整以代码为准。空池预算作废，库存不会因此转给项目方、另一奖励池或后续矿工；取整余量同样保留在账本。

质押本金与协议收入分属不同合约，退出等待七天，追加申请重置等待期。Mint 自动转款不改变 ETH/ROTAP 质押本金退出、流片收入或市场手续费的结算规则。当前没有交易池或自动添加流动性功能；后续人工建池的 ROTAP 须先通过挖矿领取。收款后的流动性用途计划不受合约强制执行。

正式数据只使用 config/task-bank.json 与 config/vectors/ 的 4663 目标信息；reference-v2/ 是历史证据。

没有已核验的主网地址时不得填入本地地址。发布前必须通过所有测试、独立审查、链上运行时代码及权限核验和浏览器源码验证。详见 README.md、SECURITY.md 与 THIRD_PARTY_NOTICES.md。
