# 安全状态与修复记录

本地验收和实现者检查不等于独立审计。当前未完成第三方独立审查，也没有可公布的正式主网源码验证记录；付款应保持关闭。

## 本次修复

1. 删除差别化零价铸造分支、地址配置及对应旧版生成记录。全部钱包执行同一支付公式。
2. 删除元件调价、修改总量与分类/钱包额度、计数迁移及流片调价入口。正式开放前封存工厂与挖矿，放弃所有实现升级权及市场管理权。
3. 将运行时任务数据与历史研究证据分离。修复向量校验中旧链 ID 的硬编码；正式构建核对 4663、全部向量根、证明、参考运行及价格配置。
4. 官网交易前核对运行时代码哈希、零管理员、治理封存、未暂停和任务冻结状态。部署、独立审查或验证证据缺失时禁止付款。
5. 为结算交易增加 Gas 余量；完成刷新后才显示交易确认，避免覆盖后续输入。
6. 公布源码、依赖锁、许可来源及构建来源记录，取消以混淆替代代码可审查性的发布方案。
7. 元件 Mint 收款改为同一笔交易自动转给固定收款人，删除元件收入记账与提款入口；转款失败回滚。正式收款人与部署者为同一公开地址，不将此资金流隐瞒为合约内锁定或自动建池。
8. ROTAP 改为固定 20,000,000 枚库存，全量初始存于挖矿账本；删除后续铸币入口。仅以已结算挖矿奖励转账释放库存，没有管理员库存提取或代币授权接口。全网初始预算为每天 7,200 枚，采用累计预算整数差结算；空池预算作废且不再释放。

## 必须保留的残余风险

- 永久放弃管理权后，没有管理员紧急暂停、补丁升级或资产救援通道。
- 固定排放不保证代币价格、买盘、收益持续性或 ETH 退出；当前没有交易池。
- Mint 的价款及协议费会自动进入部署者钱包。后续用于流动性的计划不受合约用途限制；当前没有自动建池或锁仓安排。奖励库存与收款 ETH 分属不同地址，不能将项目钱包余额写成池储备。
- 初始 `totalSupply` 已包含全部 20,000,000 枚库存，并非全部已流通或已挖出。空池作废预算及取整余量可能永久留在账本，累计实际领取量可低于固定总量。
- 原项目源码不可得，已观察测试不能证明所有未观察边界完全等价；本版权限模型已按要求改变。
- 历史任务参考数据的权利状态未由本项目 MIT 许可解决，需要独立审查确认。

## 第三方审查的证据要求

公开审查者身份、范围、源码提交/源码哈希、报告链接、问题严重性、修复提交和复核结果。未获得这些证据，不创建“已审计”标识，也不将实现者自行生成的 JSON 当作独立审计。
