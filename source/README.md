# ROtap

面向 Robinhood Chain（4663）的公开电路协议与像素风官网。

## 发布状态

当前没有已核验的主网部署记录，付款保持关闭。源码、测试与本地验收结果不等同于独立审计或主网部署。独立审查、部署交易及浏览器源码验证各自记录，不以空链接或测试地址替代。

## 可复现构建

使用 Node.js 24.19.0、npm 11.17.0、Solidity 0.8.30；依赖版本以 package-lock.json 为准。先执行 `npm ci --ignore-scripts`，再执行 `npm run compile:v2`、`npm test`、`npm run build`。`node scripts/prepare-github-pages.mjs` 生成 /rotap/ 子路径网站。测试浏览器默认为 Windows Edge，可通过环境变量 ROTAP_BROWSER_EXECUTABLE 指定。

合约编译固定 optimizer runs=200、viaIR=true、evmVersion=paris。构建检查 4663 网络、发行配置、100 项任务、25,600 个证明与参考执行；不一致即中止。public/ 为静态页面源文件，src/ 为完整前端，contracts/ 为合约源码。构建输出不是唯一可取得的代码形式。

公开仓库的 source/ 包含本项目源码、锁文件、测试和部署脚本。网站 build-provenance.json 记录源码树哈希、源码提交、构建工具与产物哈希；源码提交与网站发布提交分别可查。源码提交中构建命令产生的 app.js、launch.js 和 ABI 应与该次发布记录一致。

## 固定权限

元件单价为 0.0002445 ETH，每笔协议费为 0.0003227 ETH；所有钱包一视同仁。NAND/LATCH 共用 1,000,000 枚终身累计上限，消耗不恢复额度。定价、额度及流片费用没有修改接口。

正式开放前，工厂与其信标、挖矿、两个市场及账户信标全部放弃管理权。挖矿封存且未暂停，任务冻结；不存在恢复权限的通道。部署后的管理员不能调价、扩大上限、任意增发、暂停、修改奖励或升级实现。工厂及挖矿的管理接口保留于初始化阶段，正式发布证据必须证明这些接口已永久不可调用。固定规则不提供管理员紧急修复通道。

## 资金与退出

Mint 和流片收入存于相应合约的收款余额；市场手续费单独记账；开户、账户执行与限时加成费用转至指定收款人。收款人是 0x8638636536Ed50fC1cCCDFDa1790aCC83E39643A。用户 ETH/ROTAP 质押本金位于独立合约，协议收入提取接口无法动用本金。

质押退出返还原资产，等待七天；追加申请合并金额并从最后一次申请重新计时。退出 ROTAP 不是兑回 ETH。本版本没有 ROTAP/ETH 池、初始流动性、回购义务或 ETH 赎回承诺。协议收入不会自动添加流动性。未来卖出或流动性份额退出取决于真实买方、储备和池规则。

ROTAP 用于协议质押。排放公式只约束发行数量，不证明收益可持续，也不构成投资回报。
