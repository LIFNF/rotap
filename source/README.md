# ROtap

面向 Robinhood Chain（4663）的公开电路协议与像素风官网。

## 发布状态

当前没有已核验的主网部署记录，付款保持关闭。源码、测试与本地验收结果不等同于独立审计或主网部署。独立审查、部署交易及浏览器源码验证各自记录，不以空链接或测试地址替代。

## 可复现构建

使用 Node.js 24.19.0、npm 11.17.0、Solidity 0.8.30；依赖版本以 package-lock.json 为准。先执行 `npm ci --ignore-scripts`，再执行 `npm run compile:v2`、`npm test`、`npm run build`。`node scripts/prepare-github-pages.mjs` 生成 /rotap/ 子路径网站。测试浏览器默认为 Windows Edge，可通过环境变量 ROTAP_BROWSER_EXECUTABLE 指定。

合约编译固定 optimizer runs=200、viaIR=true、evmVersion=paris。构建检查 4663 网络、发行配置、100 项任务、25,600 个证明与参考执行；不一致即中止。public/ 为静态页面源文件，src/ 为完整前端，contracts/ 为合约源码。构建输出不是唯一可取得的代码形式。

公开仓库的 source/ 包含本项目源码、锁文件、测试和部署脚本。网站 build-provenance.json 记录源码树哈希、源码提交、构建工具与产物哈希；源码提交与网站发布提交分别可查。源码提交中构建命令产生的 app.js、launch.js 和 ABI 应与该次发布记录一致。

## 固定权限

元件单价为 0.0002445 ETH，每笔协议费为 0.0003227 ETH；所有钱包一视同仁。NAND/LATCH 共用 1,000,000 枚终身累计上限，消耗不恢复额度。定价、额度及流片费用没有修改接口。

正式开放前，工厂与其信标、挖矿、两个市场及账户信标全部放弃管理权。挖矿封存且未暂停，任务冻结；不存在恢复权限的通道。部署后的管理员不能调价、扩大上限、任意增发、暂停、修改奖励或升级实现。工厂及挖矿的管理接口保留于初始化阶段，正式发布证据必须证明这些接口已永久不可调用。固定规则不提供管理员紧急修复通道。

## 资金与退出

Mint 支付先由元件合约核对金额并完成铸造，再于同一笔交易自动转至固定收款人；转款失败则整笔 Mint 回滚。正式发行的元件价款和协议费均转至部署者 0x8638636536Ed50fC1cCCDFDa1790aCC83E39643A。元件合约不累计待提款收入，也没有 Mint 提款接口。流片收入与市场手续费继续在各自合约单独记账；开户、账户执行与限时加成费用按各自规则结算。用户 ETH/ROTAP 质押本金位于独立合约，协议收入结算不能动用本金。

质押退出返还原资产，等待七天；追加申请合并金额并从最后一次申请重新计时。退出 ROTAP 不是兑回 ETH。本版本没有 ROTAP/ETH 池、初始流动性、回购义务或 ETH 赎回承诺。Mint 收款计划用于后续人工添加流动性，合约不执行建池、配对或收款后的用途限制；该计划不代表已经添加流动性。未来用于配对的 ROTAP 必须先经挖矿领取，不能从奖励库存直接划拨。未来卖出或流动性份额退出取决于真实买方、储备和池规则。

## ROTAP 库存与挖矿分配

ROTAP 精度为 8 位，总量固定为 20,000,000 枚。挖矿账本创建代币时一次性将全部总量记入自身余额；部署者、项目钱包和用户没有初始代币分配。代币没有后续增发接口，账本没有管理员提取、代币授权或库存救援接口。账本只能将已结算的挖矿奖励转给相应领取人。领取后用户可转账、质押，或在未来自行参与真实存在的交易池。

初始全网排放预算为每天 7,200 枚，每 126,000,000 秒减半；该数字是全网预算，不是单台矿机收益。每个减半周期采用累计预算的整数差计算，避免频繁结算改变该周期的全局预算。正常规则将预算按 99% / 1% 分给已验证与未验证池，并按有效权重分配；最小单位取整以合约为准。空池对应预算作废，不追补、不转给另一池，也不再释放；相应代币留在账本中锁定。累计预算最多计入 20,000,000 枚。

`totalSupply` 表示已经创建的全部代币库存，不等于流通量。`totalClaimed` / `totalMined` 表示已由挖矿实际领取的累计数量；未领取奖励与作废预算均不计入已领取数量。账本余额包含尚未领取或尚未分配的库存，以及永久不再释放的作废预算和取整余量。ROTAP 用于协议质押；固定分配公式不证明收益可持续，不承诺价格或买方，也不构成投资回报。

## 历史参考与差异

reference-v2/ 只保存原项目公开接口与链上研究证据。链 196、旧地址、原资产名称不得进入正式客户端配置。config/task-bank.json 与 config/vectors/ 是 4663 的正式数据，链上参考电路由本次部署创建并核对全部根与规格。

本项目独立编写合约与前端，不拥有原项目的品牌或第三方源码。未取得授权的原站压缩脚本、页面和资源不进入公开源码包。公开链上测试数据及可执行电路的来源见 reference-v2/task-migration-provenance.json；不将这些来源宣称为本项目原创。若其权利状态无法满足正式分发要求，应在独立审查中解决，不能用本项目 MIT 许可证覆盖第三方权利。

本版按用户要求采用固定权限、统一付费、Mint 自动转款和 ROTAP 质押。研究对象的 21,000,000 枚上限及领取时铸币方式属于历史参考；本版明确改为 20,000,000 枚固定库存、由挖矿领取释放。因此不再宣称与 Fab X 的管理员、资金流或代币发行方式完全相同。
